# cash.c
Aqui mostro o passo a passo do meu exercício favorito do CS50x, é importante dizer que meu preferido é o fiftyville, mas não posso usá-lo como exemplo pois não é interativo com usuários. O exercício escolhido foi: Cash, onde o usuário nos dá um valor em cents americanos, e a máquina decompõe esse valor no mínimo número de moedas possível!

Os centavos americanos são divididos dessa maneira:

<img width="1600" height="653" alt="image" src="https://github.com/user-attachments/assets/d5236fb1-b0d7-4c76-9f2c-6e6b03e02774" />

Portanto, o código irá analisar o valor do troco, decompor ele no mínimo número de moedas possível e nos passar o número de moedas que são necessárias para decompor aquele valor.

Primeiro, no terminal o código nos pedirá o troco:

<img width="113" height="20" alt="Screenshot 2026-10-11 at 11 32 19" src="https://github.com/user-attachments/assets/cfa4a0bf-ccd8-4fbc-8f82-4bd10b46562f"/>

Podemos colocar qualquer valor, por exemplo, 450.

<img width="121" height="30" alt="Screenshot 2026-10-11 at 11 36 44" src="https://github.com/user-attachments/assets/b87019a3-68ff-4067-864e-4a43a40cfbae" />

E então ele nos retorna o número de moedas mínimos que precisamos para decompor o valor digitado pelo usuário.
